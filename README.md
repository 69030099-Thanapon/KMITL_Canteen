# KMITL Canteen

Python Desktop App สำหรับสั่งอาหารล่วงหน้า พัฒนาด้วย CustomTkinter

## สถานะงานวันที่ 28 กันยายน 2026

- เปิดหน้าต่างแอปจาก `main.py`
- เลือกโรงอาหาร: คณะครุศาสตร์ คณะวิทยาศาสตร์ และโรงอาหารพระเทพฯ
- แสดงร้านเฉพาะโรงอาหารที่เลือก
- เลือกร้านเพื่อดูเมนูพร้อมราคา
- ย้อนกลับไปเลือกร้านและโรงอาหารได้
- ข้อมูลปัจจุบันเป็นตัวอย่าง 3 โรงอาหาร 9 ร้าน และ 18 เมนู

ยังไม่มีตะกร้า การสั่งซื้อ การชำระเงิน หรือการเชื่อมต่อฐานข้อมูล
งานถัดไปคือเลือกเมนูและเพิ่มลงตะกร้า ส่วนการตกแต่ง UI จะทำภายหลัง

## วิธีรัน

ใช้ Python (เครื่องที่พัฒนาใช้ Python 3.14) แล้วรันจากโฟลเดอร์โปรเจกต์:

```bash
python -m pip install -r requirements.txt
python main.py
```

## ไฟล์หลัก

- `main.py`: ตั้งธีมและเริ่มแอป
- `Frontend/app.py`: หน้าต่าง ข้อมูลตัวอย่าง และการเปลี่ยนหน้า
- `Backend/`: เตรียมไว้สำหรับการทำงานเบื้องหลังในขั้นต่อไป
