# KMITL Canteen

Python Desktop App สำหรับสั่งอาหารล่วงหน้า พัฒนาด้วย CustomTkinter

## สถานะงานวันที่ 10 ตุลาคม 2026

- เปิดหน้าต่างแอปจาก `main.py`
- เลือกโรงอาหาร: คณะครุศาสตร์ คณะวิทยาศาสตร์ และโรงอาหารพระเทพฯ
- แสดงร้านเฉพาะโรงอาหารที่เลือก
- แสดงรายการเมนูแบบย่อ กดเมนูเพื่อเปิดหน้าตัวเลือกเฉพาะรายการ
- ร้านข้าวแกงเลือกราด 1 อย่าง (40 บาท) หรือ 2 อย่าง (50 บาท) เพิ่มข้าวได้ 5 บาท
- ตรวจว่าจำนวนกับข้าวที่เลือกตรงกับแบบ 1 อย่างหรือ 2 อย่างก่อนเพิ่มลงตะกร้า
- ร้านตามสั่งเลือกเนื้อสัตว์ ธรรมดา/พิเศษ และไข่เพิ่มเติมได้
- ร้านข้าวมันไก่เลือกธรรมดา/พิเศษและเพิ่มไก่ได้
- ร้านก๋วยเตี๋ยวเลือกเส้น น้ำ/แห้ง และธรรมดา/พิเศษได้
- ใส่หมายเหตุถึงร้านและดูราคาที่เปลี่ยนตามตัวเลือกได้ โดยไม่แสดง +0 บาท
- เพิ่มอาหารลงตะกร้า รายการที่มีตัวเลือกและหมายเหตุเหมือนกันจะรวมจำนวน
- ปรับจำนวนและลบรายการในตะกร้า พร้อมอัปเดตจำนวนและยอดรวม
- แสดงตะกร้าแยกตามโรงอาหารและร้าน เลือกดูหรือแก้ไขตะกร้าแต่ละร้านได้
- ย้อนกลับไปเลือกร้านและโรงอาหารได้
- แยกโค้ดหน้าจอ ข้อมูลตัวอย่าง การคิดราคาเมนู และการจัดการตะกร้าออกจากกัน
- กรอกชื่อและเบอร์โทรผู้รับ พร้อมตรวจข้อมูลก่อนแสดงหน้าตรวจรายการ
- เลือกวันรับอาหารจากปฏิทินและเลือกเวลาจากรายการ โดยตรวจว่าเป็นเวลาในอนาคต
- ตรวจรายการของร้านที่เลือกและย้อนกลับไปแก้ข้อมูลผู้รับได้ โดยยังไม่ส่งคำสั่งซื้อจริง

## ข้อจำกัดปัจจุบัน

- โรงอาหาร 3 แห่ง ร้าน 9 ร้าน เมนู และราคาเป็นข้อมูลตัวอย่างในโค้ด
- ตะกร้าเก็บชั่วคราวในหน่วยความจำ ปิดแอปแล้วข้อมูลจะหาย
- ยังไม่มีการยืนยันคำสั่งซื้อ การชำระเงิน การติดตามสถานะ หรือการเชื่อมต่อฐานข้อมูล
- ยังไม่มีหน้าฝั่งร้านค้าสำหรับจัดการออเดอร์

## งานถัดไป

1. สร้างตาราง SQLite สำหรับคำสั่งซื้อและรายการอาหาร โดยสั่งครั้งละหนึ่งร้านก่อน
2. เชื่อมต่อฐานข้อมูล เพิ่มการยืนยันคำสั่งซื้อจริง และเปิดดูประวัติได้
3. เพิ่มหน้าร้านค้า การติดตามสถานะ และการชำระเงินแยกร้าน
4. กลับมาเพิ่มตัวเลือกร้อน/เย็น/ปั่นตามความเหมาะสมของเครื่องดื่มแต่ละเมนู
5. ทดสอบการทำงานและปรับแต่ง UI

## วิธีรัน

ใช้ Python (เครื่องที่พัฒนาใช้ Python 3.14) แล้วรันจากโฟลเดอร์โปรเจกต์:

```bash
python -m pip install -r requirements.txt
python main.py
```

## ไฟล์หลัก

- `main.py`: ตั้งธีมและเริ่มแอป
- `Frontend/app.py`: หน้าต่างหลัก การเปลี่ยนหน้า และหน้าตะกร้าแยกร้าน
- `Frontend/menu_page.py`: รายชื่อเมนู หน้าตัวเลือกอาหาร และช่องหมายเหตุ
- `Backend/sample_data.py`: ข้อมูลโรงอาหาร ร้าน เมนู ตัวเลือก และราคาตัวอย่าง
- `Backend/menu.py`: ตรวจตัวเลือกข้าวแกงและคำนวณราคาต่อรายการ
- `Backend/cart.py`: เพิ่มอาหาร ปรับจำนวน ลบรายการ แยกตามร้าน และคำนวณยอดตะกร้า
- `Backend/checkout.py`: ตรวจชื่อ เบอร์โทร และวันเวลารับอาหาร
- `Frontend/checkout_page.py`: กรอกข้อมูลผู้รับและตรวจรายการก่อนสั่ง
- `Frontend/date_picker.py`: ปฏิทินเลือกวันรับอาหาร
